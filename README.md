## 🚀 How to Use

### Option 1: Open Locally
1. Double-click `index.html` to open in your web browser
2. All files must stay in the same folder for everything to work

### Option 2: Deploy to a Website Host

**GitHub Pages (Free & Recommended):**
1. Create a GitHub account at https://github.com
2. Create a new repository called `portfolio` or your username
3. Upload all files from this folder
4. Go to Settings > Pages
5. Select "main" branch and click Save
6. Your site will be live at `https://yourusername.github.io/portfolio`

**Netlify (Free):**
1. Go to https://netlify.com
2. Drag and drop this entire folder onto Netlify
3. Your site goes live instantly with a custom URL

**Other options:** Vercel, Render, Firebase Hosting

## 📝 To Customize

1. **Update content:** Edit text directly in `index.html`
2. **Change colors:** Modify CSS variables at the top of `index.html` (inside `<style>` tag)
3. **Replace photo:** Replace `milton_raille.jpg` with your new photo (keep same filename)
4. **Update resume:** Replace `My_Resume.pdf` with your new PDF (keep same filename)
5. **Change video:** Update the Google Drive link in the iframe `src` attribute

## 🔗 Important Settings

**Google Drive Video:**
Make sure your video sharing is set to "Anyone with the link can view" for it to display on the website.

## 💡 Tips

- Keep all files in the same folder
- Don't rename files unless you also update the references in `index.html`
- Test the site by opening `index.html` in multiple browsers
- For best performance, compress images before uploading
